# AI 评测治理模块 P1 案例中心实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 在 AI 中台后端交付可运行、可测试、可审计的评测案例中心，覆盖案例创建、查询、编辑、审核、归档和幂等导入。

**架构：** 在现有 Spring Boot 模块化单体中新增独立 `com.yiwei.midplat.evaluation.casecenter` 限界上下文，使用 JPA 聚合维护案例状态，Flyway 管理数据库结构，MockMvc 锁定 REST 契约。所有写操作通过应用服务完成并追加脱敏审计记录，不允许控制器直接访问仓储。

**技术栈：** Java 17、Spring Boot 3.2.5、Spring Data JPA、Jakarta Validation、Flyway、PostgreSQL/H2、JUnit 5、MockMvc。

**规格：** `docs/superpowers/specs/2026-08-29-AI数据飞轮与评测治理模块设计及建设跟踪.md`

**执行状态：** P1 任务 1–7 已完成；代码基线为 `c39d983`，最终独立复核结论为可合入。

## 全局约束

- P1 只实现案例中心，不提前实现数据集、评测运行、实验对比、门禁或跨平台主动拉取。
- 所有主键使用现有 `Identities.newId()` 生成的 32 位字符串。
- 可变案例聚合继承 `BaseEntity`，保留创建时间、更新时间和乐观锁版本。
- 案例不提供物理删除接口，只允许 `ACTIVE -> ARCHIVED`。
- 导入内容必须已脱敏；输入、期望内容和完整输出不得写入审计摘要或应用日志。
- `api_key`、平台 Token、数据库密码不得进入评测表、审计表、异常详情或前端响应。
- 来源引用非空时以 `(source_type, source_ref)` 保证幂等；同引用不同内容返回 HTTP 409。
- 已审核案例不可编辑；被驳回案例编辑后回到 `DRAFT`；归档案例不可编辑或审核。
- 每个生产代码任务严格执行“失败测试 → 最小实现 → 通过测试 → 提交”。
- 每个任务完成后同步更新规格文档第 16、17、20 节。

- [x] **步骤 3：实现稳定 SHA-256 哈希器**

```java
final class EvaluationCaseHasher {
    private EvaluationCaseHasher() {}

    static String hash(
            CaseSourceType sourceType,
            String sourceRef,
            String inputText,
            String expectedJson,
            EvaluatorType evaluatorType) {
        String canonical = String.join("\u001f",
                sourceType.name(), normalize(sourceRef), normalize(inputText),
                normalize(expectedJson), evaluatorType.name());
        try {
            byte[] digest = MessageDigest.getInstance("SHA-256")
                    .digest(canonical.getBytes(StandardCharsets.UTF_8));
            return HexFormat.of().formatHex(digest);
        } catch (NoSuchAlgorithmException ex) {
            throw new IllegalStateException("SHA-256 不可用", ex);
        }
    }

    private static String normalize(String value) {
        return value == null ? "" : value.replace("\r\n", "\n").trim();
    }
}
```

public List<CaseView> list(CaseFilter filter) {
    return repository.search(
            blankToNull(filter.platformId()), blankToNull(filter.category()),
            filter.severity(), filter.reviewStatus(),
            filter.lifecycleStatus() == null ? CaseLifecycleStatus.ACTIVE : filter.lifecycleStatus())
        .stream().map(this::toView).toList();
}

```java
@Transactional
public CaseView importCase(ImportCaseCmd cmd) {
    if (cmd.sourceType() == CaseSourceType.MANUAL) {
        throw new IllegalArgumentException("导入案例不能使用 MANUAL 来源");
    }
    validatePlatform(cmd.platformId());
    String sourceRef = DomainAssertions.requireText(cmd.sourceRef(), "sourceRef 不能为空");
    String expectedJson = writeExpected(cmd.expected());
    String hash = EvaluationCaseHasher.hash(
            cmd.sourceType(), sourceRef, cmd.inputText(), expectedJson, cmd.evaluatorType());

    Optional<EvaluationCase> existing = repository.findBySourceTypeAndSourceRef(
            cmd.sourceType(), sourceRef);
    if (existing.isPresent()) {
        if (!existing.get().getContentHash().equals(hash)) {
            throw new ConflictException("同一来源引用已存在不同内容");
        }
        return toView(existing.get());
    }

    EvaluationCase entity = EvaluationCase.createImported(
            Identities.newId(), blankToNull(cmd.platformId()), cmd.name(), cmd.category(),
            cmd.severity(), cmd.sourceType(), sourceRef, cmd.inputText(), expectedJson,
            cmd.evaluatorType(), hash);
    repository.save(entity);
    auditService.record("CASE_IMPORTED", entity, cmd.sourceType().name());
    return toView(entity);
}
```

数据库唯一索引仍是并发下的最终保护。捕获唯一约束异常后重新查询同一来源：哈希一致返回已有记录，哈希不一致抛 `ConflictException`。
