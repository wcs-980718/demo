# AI 评测治理端到端验收计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 在真实 PostgreSQL、真实 HTTP 模型协议和真实浏览器页面上证明 P1–P5 主链路可用、安全、可恢复且可审计。

**架构：** 自动化后端端到端测试覆盖完整业务状态；运行态验收使用随机 PostgreSQL schema、受控假 OpenAI 服务、实际 Spring Boot 与 Umi 前端；浏览器按用户路径完成案例、数据集、运行、对比和门禁操作。

**技术栈：** JUnit 5、MockMvc、JDK HttpServer、PostgreSQL 16、Spring Boot、Umi、浏览器自动化、curl/psql。

**规格：** `docs/superpowers/specs/2026-08-29-AI数据飞轮与评测治理模块设计及建设跟踪.md`

## 2026-08-30 验收范围调整

用户要求尽快完成并只做最基本测试。最终验收保留一条真实 PostgreSQL + 真实 Spring Boot + 假 OpenAI HTTP + 真实浏览器的成功主链路，并复用各阶段已经完成的错误、并发、恢复和安全测试，不再新建重复覆盖相同 API 的大型组合 JUnit，也不重复跑全部错误矩阵。此调整不减少产品能力，只减少重复验收工作量。

## 全局约束

- 测试数据库使用名称前缀固定的随机 schema，不触碰现有业务 schema；结束后显式删除并确认残留数为 0。
- 假模型服务只监听本机随机端口，不读取或输出真实密钥。
- 端到端夹具只使用完全虚构、无隐私的中文数据。
- 验收失败必须先写或保留可复现失败测试，再修复生产代码。
- 最终报告必须包含命令、测试数量、浏览器截图、已知限制和独立复核结论。
