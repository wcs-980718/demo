# 评测治理最小真实运行验收

## 验收范围

本轮按用户“尽快完成、只做最基本测试”的要求，将原计划中的后端组合测试和运行脚本合并为一条更直接的真实 HTTP 主链路，不再重复增加一套与现有 API/真实 PostgreSQL 测试重叠的 JUnit 大用例。

实际链路为：

1. 在固定安全前缀的随机 PostgreSQL schema 中启动真实 Spring Boot。
2. 启动仅监听 `127.0.0.1` 随机端口的假 OpenAI 服务。
3. 通过真实 `/api` 创建模型、提示词和平台绑定。
4. 创建并审核案例，创建评测集、编排案例并冻结版本。
5. 连续创建基线与候选运行，真实调用假模型并轮询到终态。
6. 通过实验比较确认逐案例结果为 `UNCHANGED`。
7. 创建发布门禁策略并生成 `PASS` 决策。
8. 读取治理总览，确认案例数、冻结版本数和最近通过率。
9. 检查 HTTP 响应、后端日志和假模型日志均不包含测试令牌。
10. 停止进程，删除且确认随机 schema 残留为零。

## 执行命令

```bash
mvn -q -DskipTests package
scripts/evaluation-e2e/run-e2e.sh
```
